
# BARÜ TECH

## Proje Hakkında
BARÜ TECH, Bartın Üniversitesi öğrencilerinin teknoloji, yazılım ve yapay zekâ alanlarındaki gelişmeleri takip edebilmesi için hazırlanmış örnek bir kampüs web sitesi projesidir.

## Sayfalar
- Ana Sayfa: Projenin tanıtımı.
- Etkinlikler: Etkinlik kartları ve canlı arama sistemi.
- Hakkımızda: Projenin amacı, vizyonu ve değerleri.

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript

## Çalıştırma
1. Projeyi bilgisayarınıza indirin.
2. Klasörü Visual Studio Code ile açın.
3. index.html dosyasını tarayıcıda çalıştırın.

## Etkinlik Arama
Etkinlikler sayfasında kullanıcılar etkinlik başlıklarını arayabilir. Arama sistemi büyük-küçük harf duyarsızdır, boşlukları temizler ve sonuç sayısını gösterir.
